# seventh_task_rag

Учебный RAG: локальные документы режутся на чанки, получают embeddings и сохраняются в Weaviate. На вопрос система ищет три ближайших фрагмента и отвечает только по ним. Если ближайший чанк слишком далёкий, модель не вызывается и ответ не выдумывается.

## Подготовка

Нужны Python 3.12 и Docker.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
docker compose up -d
```

В `.env` запишите `OPENAI_API_KEY`. Этот файл не коммитится. Weaviate поднимается локально на портах 8080 и 50051, без встроенного vectorizer: векторы считает Python.

## База знаний

Положите файлы в `knowledge_base/`:

- формат `.txt` или `.md`
- кодировка UTF-8
- один файл — один документ

PDF, DOCX и HTML загрузчик не читает. Текст из них сначала сохраните как `.txt`.

`python3 main.py` без аргументов показывает загруженные документы, их длину и число чанков. Документ режется на фрагменты по 500 символов с перекрытием 80. Граница сдвигается к переводу строки или пробелу.

## Загрузка в Weaviate

```bash
python3 main.py index
```

Команда считает embeddings моделью `text-embedding-3-small`, удаляет коллекцию `KnowledgeChunk` и создаёт её заново. Повторный запуск не оставляет дубликаты: число объектов равно числу текущих чанков. В консоли печатаются это число и один объект с `chunk_id`, `document_id`, `source_name` и началом текста.

## Вопрос

```bash
python3 main.py answer "Как подключить автоплатёж?"
```

Ответ выглядит так:

```text
Чтобы подключить автоплатёж, войдите в личный кабинет ПИК-Комфорт, откройте вкладку «Оплата» и выберите раздел «Автоплатёж, управлять услугой». Заполните поля «Сумма к оплате» (укажите 1 рубль для привязки карты) и «Лимит списываемой суммы» (максимальная сумма списания в месяц). Поставьте галочку «Я подтверждаю подключение услуги «Автоматический платёж»» и нажмите «Согласен». Затем укажите реквизиты банковской карты, с вас спишется 1 рубль, и карта привяжется. Услуга подключена, средства будут списываться 15 числа каждого месяца.
Контекст достаточен: да
Источники:
- 05_nastrojka_avtoplatyozha-0 | 05_nastrojka_avtoplatyozha.txt
- 05_nastrojka_avtoplatyozha-1 | 05_nastrojka_avtoplatyozha.txt
```

`chunk_id` — номер фрагмента внутри файла, `source_name` — имя этого файла. «Контекст достаточен: да» значит, что ответ построен по найденным фрагментам.

Если ближайший чанк дальше порога distance 0.55, модель не вызывается:

```text
В базе знаний нет достаточно близкого контекста, чтобы ответить на этот вопрос.
Контекст достаточен: нет
Источники:
- нет
```

Так система отвечает, например, на вопрос «Какая столица Франции?»: в базе нет такого текста, а ближайший чужой документ слишком далеко.

## Demo-вопросы

Эти пять вопросов база закрывает своими документами:

- В какое время нельзя проводить шумные ремонтные работы в Москве?
- Как зарегистрироваться в личном кабинете ПИК-Комфорт?
- Как подключить автоплатёж?
- Нужно ли передавать показания счётчиков, если не живу в квартире?
- Чем опасна незаконная перепланировка?

```bash
python3 main.py evaluate
```

Команда печатает для них distance, `source_name` и решение «ответ», а для пяти посторонних вопросов — «отказ».

## Другие команды

- `python3 main.py ask "вопрос"` — только поиск, без ответа модели. Меньшая distance означает более близкий чанк.
- `python3 main.py demo` — пять вопросов, semantic search и hybrid search.
- `python3 main.py compare` — тот же вопрос без фрагментов базы и с ними.
- `python3 main.py evaluate` — пять удачных вопросов и пять посторонних.

Ответ строится по semantic top-3. Hybrid остаётся в `demo`: он может поднять другой фрагмент того же файла, но distance порога с ним не сравнивается.
